# Proposed release v1.2.0 — R3 statistical evidence

Unpublished candidate. Preserves the original model tree and adds compact saved test-prediction inputs
for 1,326 fits. Reports the directed and bidirectional paired results together and limits interpretation
to the evaluated implementations. Adds manifest-complete input checks, pairing/identity checks, portable
statistics, finite-simulation corrected inference and regression tests. Withdrawn per-site tests are removed.

No training is performed by this revision. Historical one-shot scripts are excluded from the R3 public entry.
The archive includes file lineage, not the original feature cache or full training reconstruction.
Old version DOIs remain attached to their old releases. The project concept DOI remains unchanged;
the 1.2.0 version DOI will be recorded after Zenodo publication. No release is authorized by this document.
